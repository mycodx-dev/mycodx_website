# 국립창원대학교 업무협약 소식 게시

체결일과 게시일은 **2026-11-25**입니다. 한국어·영어·프랑스어·일본어 제목·요약·본문을 제공합니다. 사진은 포함하지 않습니다.

운영 사이트는 `NEWS_CMS_ENABLED=true`로 Supabase의 공개 소식을 읽습니다. 저장소의 `news.json`만 수정하거나 코드를 배포해도 기존 DB 게시글의 번역은 바뀌지 않습니다.

## 기존 게시글의 번역 보완

2026-11-25 운영 API에서 협약 글의 네 언어 반영을 확인했습니다. 다른 네 소식의 프랑스어·일본어 보완은 [소식 다국어 번역 적용](news-translations-setup.md)을 따릅니다. 아래는 협약 번역이 아직 없는 환경을 위한 절차입니다.

최초 등록 SQL은 한국어만 담고 있어 영어·프랑스어·일본어 화면에서 한국어가 대신 표시되었습니다. 이미 게시된 협약 글은 아래 새 SQL만 실행하면 됩니다.

1. 운영 Supabase 프로젝트의 **SQL Editor → New query**를 엽니다.
2. [`202611250002_changwon_mou_translations.sql`](../supabase/migrations/202611250002_changwon_mou_translations.sql)의 전체 내용을 붙여 넣습니다.
3. 실행 역할이 `postgres`인지 확인하고 **Run**을 누릅니다.
4. 결과의 `draft`와 `published` 행에서 `en_ready`, `fr_ready`, `ja_ready`가 모두 `true`인지 확인합니다. 비공개 글은 `draft` 행만 반환합니다.
5. 운영 사이트의 `/news/5?lng=en`, `/news/5?lng=fr`, `/news/5?lng=ja`에서 제목·요약·본문을 확인합니다. 실제 주소는 SQL 결과의 `public_path`가 기준입니다.

이 SQL은 해당 글의 빈 번역만 채웁니다. 한국어와 이미 작성된 번역, 글 번호, 날짜, 정렬, 사진, 게시 시각을 보존하고 다른 게시글에는 영향을 주지 않습니다. 공개본과 초안을 각각 보완하므로 미게시 수정 사항이 공개되지 않으며, 비공개 글을 다시 게시하지 않습니다. 한국어 원문이 변경되어 새 번역과 맞지 않으면 전체 작업을 중단합니다. 재실행해도 이후 편집 내용을 덮어쓰지 않습니다.

화면과 API는 이미 네 언어를 지원하므로, 운영 게시글의 번역 반영에는 별도 배포가 필요 없습니다. 새 테이블, 권한 또는 환경변수 설정도 필요 없습니다.

## 처음 등록하는 환경

게시글이 아직 없는 환경에서는 아래 최초 등록 SQL을 실행한 뒤, 위 번역 보완 SQL을 이어서 실행합니다.

1. 운영 Supabase 프로젝트의 **SQL Editor → New query**를 엽니다.
2. [`202611250001_changwon_mou_news.sql`](../supabase/migrations/202611250001_changwon_mou_news.sql)의 전체 내용을 붙여 넣습니다.
3. 실행 역할이 `postgres`인지 확인하고 **Run**을 누릅니다.
4. 결과의 `is_published`가 `true`이고 `post_date`가 `2026-11-25`인지 확인합니다. `public_path`에 표시된 주소로 홈페이지에서 글을 확인합니다.

이 파일은 소식 한 건을 즉시 공개하고 실행 이력을 남깁니다. 기존 글과 초안은 유지하며, 주소 번호는 자동 배정됩니다. 기존 CES 정렬 설정도 유지됩니다. 재실행해도 중복 등록하거나 이후 수정·비공개 상태를 되돌리지 않습니다. 같은 날짜의 해당 기관 소식이 이미 등록되어 있으면 중복 방지를 위해 중단되므로 `/admin`에서 기존 글을 확인합니다.

새 테이블, Storage 버킷, 권한 또는 환경변수 설정은 필요 없습니다. 다른 마이그레이션을 다시 실행할 필요도 없습니다. 이후 내용 수정이나 비공개 전환은 `/admin`의 소식 메뉴에서 진행할 수 있습니다.

번역 보완 검증: 빌드와 기존 소식·관리자 테스트 8개 통과. 임시 PostgreSQL에서 공개 API의 번역 반환, 원문·기존 번역·다른 글·정렬·게시 시각 보존, 미게시 초안 분리, 비공개 유지, 재실행, 원문 변경 시 전체 중단을 확인했습니다. 브라우저에서는 번역된 게시 데이터의 모의 API 응답을 사용해 한국어·영어·프랑스어·일본어 목록과 상세 화면을 PC·모바일에서 확인했습니다. 이후 운영 API에서도 협약 글의 네 언어 제목·요약·본문을 확인했습니다.
